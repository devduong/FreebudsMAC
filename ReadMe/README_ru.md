## ⚠️ Важно: Только для macOS

> [!IMPORTANT]
> **FreebudsMAC разработан и оптимизирован исключительно для операционной системы macOS** (требуется macOS 13.0 Ventura или новее, полная поддержка macOS 14 Sonoma, macOS 15 Sequoia и macOS Tahoe). Приложение напрямую использует нативные системные фреймворки Apple (`IOBluetooth`, `CoreBluetooth`, `Carbon.HIToolbox` и `UserNotifications`).
>
> Если вам требуется поддержка на других платформах (**Linux** или **Windows**), пожалуйста, посетите оригинальный проект на Python/PyQt от **@melianmiko**:
> 👉 **[https://github.com/melianmiko/OpenFreebuds](https://github.com/melianmiko/OpenFreebuds)**

## ✨ Возможности

- 🎛️ **Управление активным шумоподавлением (ANC)**: Быстрое переключение между режимами **Шумоподавление (Noise Cancellation)**, **Звукопроницаемость (Awareness)** и **Выключено (Normal)**.
- 🔋 **Мониторинг заряда аккумулятора в реальном времени**: Точные проценты заряда левого наушника (L), правого наушника (R) и кейса (Case) со статусом зарядки.
- 👂 **Автоопределение ношения (In-Ear Detection)**: Автоматическая пауза при извлечении наушника из уха и возобновление воспроизведения.
- 🎚️ **Эквалайзер и звуковые профили**: Переключение профилей (По умолчанию, Усиление басов, Усиление ВЧ, Вокал) и пользовательские настройки эквалайзера.
- 🔀 **Двойное подключение (Dual-Connect / Multi-point)**: Управление сопряжёнными устройствами и быстрое переключение источника звука.
- 👆 **Настройка сенсорных жестов**: Настройка двойного/тройного касания, удержания и свайпов регулировки громкости.
- ⚡ **Игровой режим с низкой задержкой**: Снижение задержки передачи звука для игр и монтажа видео.
- ⌨️ **Глобальные горячие клавиши**: Набор системных горячих клавиш (`⌥⌘A`, `⌥⌘C`, `⌥⌘0`, `⌥⌘1`, `⌥⌘2`, `⌥⌘L`), работающих из любого приложения при работе в Menu Bar.
- 🔔 **Уведомления о низком заряде**: Всплывающие системные уведомления при разряде до 20% и 10% (автоматически скрываются через 5 секунд).
- 🚀 **Максимальная производительность**: Нативное приложение Swift, моментальный запуск, потребление ОЗУ менее 30 МБ и около 0% ЦП.
- 🌐 **Мультиязычность**: Встроенная поддержка Русского, Английского, Вьетнамского, Упрощенного китайского (简体中文), Традиционного китайского (繁體中文) и Французского языков.

### Что делать, если вашей модели нет в списке?

FreebudsMAC содержит **интеллектуальную многоуровневую систему совместимости**:

1. **Не включённые в список наушники HUAWEI / HONOR**:
   - Автоматически используется универсальный драйвер **`GenericHuaweiDriver`**.
   - Он автоматически загружает 100% стандартных обработчиков SPP (ANC, Батарея, Жесты, EQ, Dual-Connect).
   - В разделе **Выбор устройства (Device Selection)** вы можете отключить *"Автоматический выбор"* и вручную подключить любое сопряжённое устройство.
2. **Сторонние Bluetooth-наушники**:
   - Обрабатываются через **`BLEBatteryScanner` / `BLEBatteryDriver`**.
   - Пассивное чтение заряда по протоколам **Google Fast Pair (`0xFE2C`)** или стандартному сервису **GATT Battery Service (`0x180F`)**.

## 📥 Установка и первый запуск

### 1. Скачайте образ DMG
Скачайте актуальный файл `FreebudsMAC_Universal_x.x.x.dmg` со страницы [GitHub Releases](https://github.com/devduong/FreebudsMAC/releases).

### 2. Установка приложения
Откройте скачанный `.dmg` и перетащите иконку **FreebudsMAC.app** в папку **Программы** (`/Applications`).

### 3. Первый запуск и обход Gatekeeper (Безопасность macOS)

> [!WARNING]
> Так как FreebudsMAC является бесплатным проектом с открытым исходным кодом без платной подписки Apple Developer, системная защита macOS Gatekeeper при первом запуске может показать предупреждение:
> *"Не удается открыть приложение FreebudsMAC, так как не удалось проверить разработчика"* или *"macOS не может проверить, что в приложении нет вредоносного ПО"*.

**Инструкция по открытию:**
1. Откройте **Системные настройки** (System Settings) на вашем Mac.
2. Перейдите в раздел **Конфиденциальность и безопасность** (Privacy & Security).
3. Прокрутите вниз до блока **Безопасность** (Security).
4. Нажмите кнопку **"Подтвердить вход" / "Все равно открыть" (Open Anyway)** рядом с сообщением о блокировке FreebudsMAC.
5. В появившемся диалоговом окне нажмите **"Открыть" (Open)** и введите пароль учетной записи или используйте Touch ID.

*(Альтернативный способ: Удерживая клавишу `Control` (или правой кнопкой мыши), нажмите на `FreebudsMAC.app` в Finder ➔ выберите **Открыть** ➔ подтвердите нажатием **Открыть**).*

## 🛡️ Настройка системных разрешений

Для полноценной работы откройте **Настройки FreebudsMAC > Системные настройки macOS** и предоставьте 3 основных разрешения:

```
Настройки FreebudsMAC ➔ Системные настройки macOS
├── 1. Разрешение Bluetooth      ➔ Обязательно (Поиск и обмен командами с наушниками)
├── 2. Разрешение Уведомлений    ➔ Оповещения о низком заряде (Тип: Баннеры)
└── 3. Разрешение Универсального ➔ Глобальные горячие клавиши в фоновом режиме
       доступа (Accessibility)
```

### 1. 🔵 Разрешение Bluetooth
- **Назначение**: Связь по SPP/RFCOMM и BLE для чтения заряда и переключения режимов шумоподавления.
- **Предоставление**: Нажмите *"Открыть настройки Bluetooth"* или разрешите при первом системном запросе.

### 2. 🔔 Разрешение на уведомления (Предупреждения о низком заряде)
- **Назначение**: Получение системных уведомлений при падении заряда до 20% и 10%. Уведомления автоматически исчезают через 5 секунд.
- **Важная настройка**:
  - Откройте **Системные настройки** ➔ **Уведомления** ➔ **FreebudsMAC**.
  - Убедитесь, что выбран стиль предупреждений **Баннеры (Banners)**, а не «Не выбрано», чтобы уведомления корректно отображались на экране.

### 3. ⌨️ Универсальный доступ (Accessibility — Горячие клавиши)
- **Назначение**: Прослушивание системных комбинаций клавиш для быстрого переключения ANC из любого открытого приложения.
- **Предоставление**: Нажмите *"Предоставить разрешение"* в приложении, откроется **Конфиденциальность и безопасность > Универсальный доступ**, где нужно включить тумблер для **FreebudsMAC**.

#### Список горячих клавиш по умолчанию:

| Сочетание | Действие | Описание |
| :---: | :--- | :--- |
| <kbd>⌥ Option</kbd> + <kbd>⌘ Cmd</kbd> + <kbd>A</kbd> | **Циклическое переключение ANC** | Обычный ➔ Шумоподавление ➔ Проницаемость |
| <kbd>⌥ Option</kbd> + <kbd>⌘ Cmd</kbd> + <kbd>C</kbd> | **Подключить / Отключить** | Быстрое подключение или отключение наушников |
| <kbd>⌥ Option</kbd> + <kbd>⌘ Cmd</kbd> + <kbd>0</kbd> | **Выключить шумоподавление** | Обычный режим (ANC выкл) |
| <kbd>⌥ Option</kbd> + <kbd>⌘ Cmd</kbd> + <kbd>1</kbd> | **Включить ANC** | Режим активного шумоподавления |
| <kbd>⌥ Option</kbd> + <kbd>⌘ Cmd</kbd> + <kbd>2</kbd> | **Режим проницаемости** | Режим внимания / Awareness |
| <kbd>⌥ Option</kbd> + <kbd>⌘ Cmd</kbd> + <kbd>L</kbd> | **Игровой режим** | Режим низкой задержки звука |

## 🛠️ Сборка из исходного кода

### Требования
- macOS 13.0 (Ventura) или новее (рекомендуется macOS Sonoma / Sequoia / Tahoe).
- Инструменты командной строки Xcode (`xcode-select --install`) со Swift 5.9+.

### Команды сборки и запуска
```bash
# 1. Клонирование репозитория
git clone https://github.com/devduong/FreebudsMAC.git
cd FreebudsMAC

# 2. Сборка в режиме Release
swift build -c release

# 3. Запуск приложения
swift run FreebudsMAC
```
